## 下载和使用

- [CSV 表格](foods.csv)：Excel/WPS 导入，UTF-8 BOM；空单元格表示未知。
- [JSON 数据](foods.json)：保留来源、页码、位置、区间和待核对备注。
- 原始转录维护在 [`data/`](../data/)，执行 `python scripts/build_library.py` 同步所有导出与小程序。
- 执行 `python scripts/build_library.py --check` 检查导出是否与原始转录一致。

## 数据口径

热量按图中对应份量记录，不是统一每100克。去酱、带皮／去皮属于独立版本，不代表可互相累加。区间不取平均值。营养约数保留来源说明。截图发布日期、地区和当前在售状态未核实。水印遮挡值留空，图片热量与宏量营养素不一致时保留原值并备注。

Wagas、麦当劳、Tims 和袁记云饺的宏量营养值暂缺；肯德基按较清晰截图转录，不表示经过官方验证。部分餐食、包装与饮料规格仍待核对。

不使用 USDA。原图及原作者内容的再分发许可未核实，本目录仅包含结构化转录和来源说明；未上传整张截图。
